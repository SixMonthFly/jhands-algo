# jhands-algo

Jacobi 三指 12 轴灵巧手的核心算法归档，当前收录最新实机遥操作与仿真链路实际采用的**运动重定向**与**零点校准**方案。

> 本仓库仅归档核心算法源码与配置文件，不包含机械手 3D 模型（MJCF / STL）、实机日志及电机驱动闭源库；相关资产由整机工程提供。

## 一、运动重定向（手套骨架 → 12 轴关节目标）

### 核心思路

人手与三指机械手在指长比例、自由度和关节范围上存在明显差异。现行实时方案采用**规范右掌坐标系下的单帧多目标形态适配逆运动学（IK）+ 局部自碰撞修正**：

1. **输入接入与规范掌系对齐**：以约 120 Hz 订阅右手 21 关节骨架（4 帧有限队列防积压，剔除低置信度与超龄帧），将人手与机械手都归一化到同一个无量纲右掌坐标系（原点取食/中指根部中点，尺度取原点到腕部/掌基座距离），屏蔽掌型大小与手腕世界朝向差异。
2. **定向特征提取**：从手套远端四元数提取**带符号拇指 IP 弯曲角**（扣除机械手静态零位偏置，避免反伸被误映为屈曲）与**三指指腹外法向**，并做骨段几何一致性校验。
3. **多目标加权最小二乘逆解**：在相对硬限位各内缩 3° 的关节边界内，以上一帧为初值做解析雅可比有界非线性最小二乘求解（单帧最多 6 次评估），直接联合优化形态、指尖位置、捏合间距、带符号弯曲角与指腹朝向。
4. **两级局部自碰撞修正**：在 MuJoCo 中做整手前向运动学与碰撞检测（排除掌基座与三指首节根部相邻接触，穿透容限 0.05 mm）。无穿透直接输出；有穿透先沿接触法向梯度局部回退相关关节，若仍有穿透再按碰撞链分组做局部二分回溯——单指碰掌时，其余手指仍可正常跟随，避免整手冻结。

### 多目标如何“同时平衡”？（加权机制说明）

机械手只有 12 个自由度，各项几何目标之和为超定约束，无法全部同时归零。求解器把每项误差乘以权重后拼成残差向量，最小化加权平方和。这些权重并非一律写死，而是**动态近捏提权 + 按手指/指节分层的固定权重**：

| 优化项 | 权重机制 | 默认配置与作用 |
| --- | --- | --- |
| **指间相对位矢 & 间距**（拇指对食/中指） | **动态自适应** | 随指尖距离自动变化：张手时权重回落，让位给整体姿态；接近捏合时权重自动放大约 5 倍以上，优先保证对指精度与缝隙不走样（标量间距项为位矢项的 0.5 倍）。 |
| **三指指腹外法向** | 固定（命令行可调） | 默认 **2.0**，推动指腹面朝向贴合手套（仅约束面法向，不强求三轴全姿态）。 |
| **形态重建指尖位置** | 固定（命令行可调） | 默认 **1.5**，按机械手真实骨长与人手骨段方向重建指尖目标；与指腹朝向权重构成核心取舍。 |
| **手指伸展度**（弦长/总骨长） | 分手指固定 | 拇指 **3.0**、食/中指 **0.22**，重点约束与人手构型差异最大的拇指。 |
| **各指节骨段方向** | 分指节固定 | 拇指近→远 **0.18 / 0.29 / 0.34**（偏重远节）；食/中指 **0.63 / 0.47 / 0.34**（偏重近节摆向）。 |
| **六个中远端弯曲关节角** | 固定 | **0.65**，包含带符号拇指末节转角，直接参与联合优化（不再事后硬覆盖）。 |
| **相邻指骨夹角余弦 / 默认舒展正则** | 固定 | **0.10** 辅助弯曲形状一致；**0.012** 极小正则用于冗余处保稳。 |

> **控制约束原则**：实时入口不加输入低通滤波、不加时序平滑惩罚、不设单帧步长或速度上限；上一帧仅作优化初值与局部避碰回退锚点。

## 二、零点校准与实机启动衔接（仿真关节角 ↔ 12 轴电机）

### 核心思路

真机电机按当次上电维护多圈电机轴角度（度，标称 50:1 减速比），断电重启可能发生多圈跳变，且仿真 MJCF 与真机 CAN 1–12 的**轴序、正方向、单位与舒展参考角**均不相同。

现行方案采用**示教舒展位软件零点标定**（不频繁刷写驱动器内部零点，保留驱动器原始多圈计数），并配合三段式启动衔接：

1. **双模式零点标定与防错**
   - **重新标定（`--at-stretch`，首次/重启上电必用）**：真手摆至约定示教舒展位，经 2 秒只读总线扫描确认 12 轴在线、无故障、处于 `STOP` 且静止后，结合固化参考配置（含轴方向、50:1 传动比及非全零的舒展参考角）反算每轴软件零点偏置，连同驱动器置零登记哈希摘要原子落盘。
   - **同次上电复用（`--same-power`）**：加载最近有效标定，在读入与开桥前双重校验驱动器置零登记摘要未变更，防止误用过期零点。
2. **显式映射与范围校验**
   - 按关节名将 MuJoCo 顺序（拇指 → 右主指 → 左主指）重排为 CAN ID 1–12 顺序（左主指 → 右主指 → 拇指），强制校验 `calibrated=True` 与 CAN 电机角可表示范围。
3. **三段式安全启动**
   - **回舒展**：以较高刚度（`kp_code=25`）拉回标定舒展位，待 12 轴输出角误差 ≤ 2.0°、静止且稳定保持 100 ms 后，切换为柔和跟随刚度（`kp_code=10`、`kd_code=15`）；
   - **2 秒预检缓冲**：抓取首帧新鲜手套目标后，先在 MuJoCo 中对“舒展位 → 首帧目标”做 2001 点（1 ms 间隔）整手碰撞与限位校验，通过后再用 2 秒线性平滑过渡；
   - **直接实时跟随**：通过单槽最新目标邮箱推送带设备微秒时间戳的新鲜目标，桥以 200 Hz 下发 MIT 帧（遥操驱动帧回执时限 100 ms），异常或停止时确认全 12 轴 STOP 回显。

## 三、已知前提与边界

- **断电重上电依赖人工声明**：软件自动拦截驱动器置零记录变更，但重新上电后须人工在示教舒展位执行 `--at-stretch`。
- **标称传动比推算**：关节输出角由电机编码器按标称 50:1 换算，无独立外置输出轴编码器。
- **朝向与位置权衡**：默认同时优化指腹朝向与指尖位置，在三指自由度与避碰约束下存在取舍（离线基准中拇指朝向残差相对食/中指更大）。
